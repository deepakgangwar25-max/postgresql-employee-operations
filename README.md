# PostgreSQL Employee Database Operations

Hands-on SQL implementation covering Data Definition Language (DDL) and Data Manipulation Language (DML) using PostgreSQL.

## 📌 Topics Covered
- **Table Definition & Integrity:** Schema creation with constraints (`PRIMARY KEY`, `NOT NULL`, `CHECK`).
- **Schema Alterations:** Adding columns, renaming columns, and changing data types using `ALTER TABLE`.
- **Data Manipulation (DML):** Inserting records, targeted row deletion, and bulk conditional updates.
- **Data Retrieval (DQL):** Filtering records with date conditions and sorting data.

## 📁 Repository Structure
- `SQL ASSIGNMENT.sql`: PostgreSQL solution script containing table setup, data insertion, and all 10 query solutions.
- `Day_11_SQL_Assignment_Questions.docx`: Problem statements and practice questions.

## 🛠️ Database Setup & Solution Highlights
- **Engine:** PostgreSQL
- **Key Operations:**
  - Calculated column updates (`salary = salary + (salary * 0.10)`)
  - Schema modifications (`ALTER COLUMN salary TYPE INTEGER`)
  - Filtered queries using comparison operators and `ORDER BY`
